# Hz / dB — график по точкам

Минималистичный лендинг-инструмент: вводите значения **Hz** и **dB** в таблицу, нажимаете кнопку — и получаете график.

## Возможности

- ➕ Добавление / удаление строк таблицы
- 📈 Построение линейного графика по точкам (по кнопке «Построить график»)
- 🔄 Переключение осей: по умолчанию **Hz → ось Y**, **dB → ось X**, можно поменять местами
- ✔️ Валидация ввода (подсвечивает некорректные поля)
- 💾 Экспорт графика в PNG
- 📱 Адаптивный дизайн, минимализм

## Запуск

Просто откройте `index.html` в браузере — или включите GitHub Pages:

**Settings → Pages → Branch: main → Save**

## Технологии

- HTML / CSS / JavaScript (без сборки)
- [Chart.js](https://www.chartjs.org/) через CDN
